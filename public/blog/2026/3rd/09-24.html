It is a question that many had asked: How profittable are the orders in Huntcook anyways? You can earn money by orders, but you can also sell the dishes straight from the inventory. Heck, why not straight up sell the ingredients? Wouldn't that be way more time efficient? But most people would rebute that "Wouldn't it make more sense for the orders to be more profitabble than selling from the inventory?". Therefore, I decided to do some calculations for the selling prices for the ingredients, recipes, and the profits it brings using different money earning methods.

Data input is extremely time-consuming, and both me and my hands aren't a fan of grueling hand-typing for hours. Luckily, Javascript comes to save the day. With the help of the Huntcook Wiki and DevTools, I can extract the text from the relevant elements to get the ingredient/recipe names, or even turn them into Excel formulas!

For example, I want the Excel sheet to calculate the total inventory price of the items in an order (as opposed to the reward). I already have the inventory price of the dishes, but I still need to calculate the quanitity of each dish and obtain each price, surely I don't want to do that manually! So, on the Extra orders page, I run this code on Devtools:

  // Select each row containing the orders
  var rows = document.querySelectorAll(".article-table > tbody:nth-child(1) > tr:not(:has(th))")
  rows.forEach((row)=>{
  // Select the cells in a row
  var cells =row.querySelectorAll('td');
  // Prepare empty array
  var ar=[];
  // Cells 2-5 contains the dish name and quantity
  for(i=2;i<5;i++){
    // Turn the strings to Excel formula, by using VLOOKUP, it can obtain the selling price of the dishes without needing me and input everything again
  var tes=`VLOOKUP("${cells[i].querySelector("a").getAttribute("title")}",D:E,2,False)${cells[i].innerText.replace("x ","*")}`;
  // Combine the three strings together
  ar.push(tes);
  }
  console.log(ar.join("+"))
  })

Then the results for one of the orders will come out as something like VLOOKUP("Wild Game Sundubu",D:E,2,False)*4+VLOOKUP("Stewed Elk Tendons",D:E,2,False)*2+VLOOKUP("Tuna Salad",D:E,2,False)*10, might need to adjust things a bit more if there's bugs or what not.

Analysis

After only a few hours (I expected longer), I managed to add the ingredients, recipes, and extra order prices! There is also the side orders, but it seems the wiki didn't add them. So here's the link to the spreadsheet, even though there isn't any use to people, I think.

Before calculating the different between the ingredient price (The selling price of the ingredients required for the recipe) and the inventory price, you'd assume the inventory price is always higher, but nope! There's 10 recipes where if you sell them from the inventory, you will have a loss, you'd better off selling their ingredients instead! The recipe with the biggest loss is Ostrich Tartare (-17.02% -21.71%), followed by Camel Kebabs (-15.72%) and Desert Yukgaejang (-6.42%).

*It seems Fandom Wiki got the ingredients for Ostrich Tartare a bit wrong, I went ahead and corrected it

On the other hand, what brings the most profit if you sell from the inventory? The first place is Boar Hotpot (217.69%), followed by Elk Meatballs (201.47%) and Grilled Squab (127.54%)! Elk Meatballs surprised me the most, it is rather easy to make (Elk Meat * 2 + Potato * 2) but it is especially profittable? Next time when I have too many potatoes, gonna cook them en mass and sell them!

Now what about the Extra Orders? Thankfully, all of them has a higher reward than the inventory price, and that is excluding the experience and tickets!

As for the Side Orders, I might input them into the spreadsheet, or not depending how high my motivation is. Anyways, thank you for listening to this useless ramble.
